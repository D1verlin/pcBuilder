# 🖥️ PcBuilder — Конструктор ПК и Анализатор Производительности

PcBuilder — это современное веб-приложение для сборки персональных компьютеров, проверки совместимости комплектующих и прогнозирования производительности в различных игровых и рабочих сценариях (бенчмарках). Проект построен на базе строгой **Onion-архитектуры** (Луковичной архитектуры) на бэкенде (.NET 10) и отзывчивого, современного спа-клиента на фронтенде (React 19 + Tailwind CSS v4).

---

## 🚀 Технологический стек

### 🟢 Бэкенд (Backend)
*   **Платформа:** `.NET 10.0 Web API`
*   **База данных:** `SQLite` (легковесная и производительная СУБД)
*   **ORM (Доступ к данным):** `Entity Framework Core 10`
*   **Аутентификация & Авторизация:** `ASP.NET Core Identity` + `JWT Bearer Tokens`
*   **Документация API:** `Swagger (Swashbuckle)`
*   **Архитектурный паттерн:** `Onion Architecture` (разделение на Domain, Application, Infrastructure, Presentation)

### 🔵 Фронтенд (Frontend)
*   **Библиотека интерфейса:** `React 19` (Type: Module)
*   **Сборщик проекта:** `Vite 8`
*   **Стилизация:** `Tailwind CSS v4` + `PostCSS`
*   **HTTP-клиент:** `Axios` (с интерцептором авторизации)
*   **Анимации:** `Framer Motion` (для плавных микро-анимаций)
*   **Иконки:** `Lucide React`

## 🏛️ Архитектура проекта (Onion Architecture)

Проект строго разделен на независимые слои, где зависимости направлены исключительно внутрь (к ядру — Domain):

```mermaid
graph TD
    Presentation[PcBuilder.Presentation - Web API] --> Application[PcBuilder.Application - Бизнес-логика]
    Presentation --> Infrastructure[PcBuilder.Infrastructure - EF Core / СУБД]
    Infrastructure --> Application
    Application --> Domain[PcBuilder.Domain - Сущности и Интерфейсы]
    Infrastructure --> Domain

    style Domain fill:#2ecc71,stroke:#27ae60,stroke-width:2px,color:#fff
    style Application fill:#3498db,stroke:#2980b9,stroke-width:2px,color:#fff
    style Infrastructure fill:#e67e22,stroke:#d35400,stroke-width:2px,color:#fff
    style Presentation fill:#9b59b6,stroke:#8e44ad,stroke-width:2px,color:#fff
```

### Описание слоев:

1.  **`PcBuilder.Domain` (Ядро системы):**
    *   Абсолютно чистый слой без внешних зависимостей (например, от СУБД или EF Core).
    *   Содержит доменные модели/сущности (`PcComponent`, `Category`, `Build`, `BenchmarkScenario`, `BenchmarkResult`).
    *   Определяет абстракции (интерфейсы) репозиториев для взаимодействия с базой данных (`IPcComponentRepository`, `ICategoryRepository` и др.).
2.  **`PcBuilder.Application` (Слой бизнес-логики):**
    *   Содержит сценарии использования приложения (Use Cases), DTO (Data Transfer Objects) и сервисы бизнес-логики.
    *   Определяет интерфейсы прикладных сервисов (`IComponentService`, `IBuildService` и т.д.).
    *   Не зависит от деталей реализации СУБД, веб-фреймворков или UI.
3.  **`PcBuilder.Infrastructure` (Инфраструктурный слой):**
    *   Реализует доменные репозитории с использованием `Entity Framework Core` и `SQLite`.
    *   Содержит конфигурации контекста базы данных (`ApplicationDbContext`), механизм автоматических миграций и сервис автоматического наполнения данными (`SeedDataService`).
4.  **`PcBuilder.Presentation` (Точка входа / Web API):**
    *   Веб-API контроллеры, обрабатывающие HTTP-запросы и возвращающие DTO.
    *   Отвечает за аутентификацию пользователей (JWT Bearer Tokens), работу с ролями пользователей (`ASP.NET Core Identity`), CORS-политики и Swagger UI.

## ⚡ Быстрый запуск

В корне проекта находится готовый скрипт запуска **`run.bat`**, который автоматически запустит бэкенд и фронтенд в параллельных процессах.

### Требования для запуска:
1. Установленный **.NET 10 SDK** (для сборки бэкенда).
2. Установленная среда выполнения **Node.js** (версия 18+) и менеджер пакетов `npm` (для фронтенда).

### Шаги по запуску:

1. Откройте консоль в корневой папке проекта и установите зависимости фронтенда (требуется сделать один раз перед первым запуском):
   ```bash
   cd PcBuilder.Client
   npm install
   cd ..
   ```

2. Запустите файл **`run.bat`** (дважды кликните по нему в проводнике или запустите через терминал):
   ```bash
   run.bat
   ```

Скрипт автоматически:
* Скомпилирует бэкенд, применит миграции к SQLite и автоматически наполнит базу данных тестовыми комплектующими и сценариями бенчмарков.
* Запустит локальный сервер разработки фронтенда Vite.
* Выведет ссылки для доступа.

### Локальные адреса сервисов:
* **Фронтенд-приложение (Пользовательский интерфейс & Админ-панель):** [http://localhost:5173](http://localhost:5173)
* **Swagger API (Интерактивная документация бэкенда):** [http://localhost:5213/swagger](http://localhost:5213/swagger)

## 📌 Ключевые возможности приложения

### Для обычных пользователей:
1. **Конструктор совместимых сборок:** Удобный пошаговый выбор процессоров, видеокарт, оперативной памяти и материнских плат с фильтрацией по категориям.
2. **Анализ конфигурации:** Валидация сборки бэкендом на предмет совместимости комплектующих.
3. **Предсказание производительности (Бенчмарки):** Визуализация прогнозируемого FPS (кадров в секунду) сборки в различных популярных играх и профессиональных программах (например, Cyberpunk 2077, Blender Render, CS2) благодаря встроенным сценариям.

### Для администраторов (Admin Dashboard):
1. **Авторизация по JWT:** Безопасный вход с получением токена доступа, сохраняемого в локальное хранилище.
2. **Управление категориями:** CRUD операции над категориями компьютерного железа.
3. **Менеджер комплектующих:** Добавление, редактирование и удаление конкретных деталей (процессоры, видеокарты) с указанием их уникальных характеристик.
4. **Управление бенчмарками:** Привязка результатов тестов FPS к конкретным комплектующим в разрезе различных сценариев.
5. **Контроль сборок:** Просмотр и удаление сохраненных пользователями конфигураций.
6. **Быстрый Сброс/Сидинг:** Возможность моментально сбросить базу данных и наполнить ее исходными сбалансированными демонстрационными данными через бэкенд-эндпоинт `/api/debug/seed`.
