error Материнская плата / Процессор

Требуется обновление BIOS

Выбранный чипсет материнской платы (B550) может потребовать обновления BIOS перед использованием выбранного процессора (серия Ryzen 5000). Без этого обновления система не сможет пройти POST.

build
Рекомендуемое решение Убедитесь, что материнская плата поддерживает функцию «BIOS Flashback» для обновления без установленного совместимого процессора, или запросите услугу обновления BIOS у продавца.
warning Корпус / Видеокарта

Ограничение физических размеров

Длина выбранной видеокарты (RTX 4090) составляет 342 мм. Выбранный корпус (NZXT H510) поддерживает видеокарты максимальной длиной до 381 мм. Хотя она помещается, зазор для радиаторов переднего крепления будет крайне ограничен (останется около 14 мм).

straighten
Рекомендуемое решение Рассмотрите возможность верхнего монтажа жидкостного охлаждения процессора или выбора более просторного корпуса (например, ATX Full Tower) для оптимального воздушного потока и простоты сборки.
info Память / Материнская плата

Ограничение скорости RAM

Вы выбрали память 6000МТ/с, но выбранная материнская плата изначально поддерживает до 5200МТ/с без включения профилей XMP/EXPO в BIOS.

speed
Рекомендуемое решение Замена оборудования не требуется. Не забудьте включить профиль экстремальной памяти в UEFI/BIOS при первой загрузке для достижения заявленных скоростей.
